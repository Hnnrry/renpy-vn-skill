# Ren'Py 视觉小说手册 · AI Skill

**不用写代码，把 OC / 小说 / 故事做成文字游戏。**

一个给 AI 助手用的 Skill（技能手册）：装进你的 AI，它立刻就懂 Ren'Py 工程的界面定制与机制改造——不用你从零教它，也不用你会写代码。

```
你：我想把小说做成橙光那种文字游戏，但我不会代码
AI：（读完这个 Skill）装 SDK → 建工程 → 立绘站位这样摆 → 对话框这样调 → 打包发布走这条命令
```

---

## 这是什么

做文字游戏真正的门槛不在"写代码"，在于**别人踩过的坑你还要再踩一遍**：立绘被拉伸变形、中文字体显示成方框、改完启动器里看不到改动、打包出来一跑就崩……

这份手册是这些坑踩完之后沉淀下来的东西：

- **SDK 官方文件地图**（带行号）——查参数不用满仓库翻
- **界面布局逐像素实测值**——立绘占屏高、对话框高度、文字左缘怎么对，全是量出来的数
- **八大玩法机制结构**——线索、背包、笔记、推理链、常驻 HUD、现场热区、新手引导、结案手记
- **踩坑清单**——17+ 条真实翻车记录与正解
- **自检脚本**——改完布局自动量像素对照设计稿

它是一份**手册型 Skill**：喂给你在用的 AI 助手（Claude Code / 支持 Skill 的助手 / 本地 Agent），让 AI 按专业做法带你做，而不是每次瞎猜。
